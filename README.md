# Donut Gamble Tracker

DonutSMP gambling / host mod by **__Death____** · Fabric · Minecraft 1.21.11 · client-side

This repository only hosts the **releases** (the mod jar + the signed update file). The source code is not public.

## Install
1. Install Fabric Loader for 1.21.11 (Fabric API not needed, Mod Menu optional).
2. Download `donut-gamble-tracker-<version>.jar` from [Releases](../../releases/latest) and put it in your `mods` folder (remove older versions first).
3. Launch, press **J**: the **License** page shows your HWID.

## Licence key
The mod needs a key. Copy your HWID from the License page and send it to __Death____; paste the key you get and press **Activate**. A key only works on the PC it was made for.

## Updates
Installed copies update themselves: new versions are downloaded in the background, checked against __Death____'s signature, and installed when Minecraft closes.
